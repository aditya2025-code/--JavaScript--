# -- JavaScript --

A collection of JavaScript notes and practice code, organized by topic. This repo is meant as a personal learning log for working through core JavaScript concepts, one folder at a time.

## 📁 Structure

The repo is organized into numbered folders, each covering a specific topic:

| Folder | Topic |
|---|---|
| `00_Notes` | General notes, concepts, and reference material |
| `1_String` | Strings — methods, manipulation, and examples |
| `2_Boolean&Numbers` | Booleans, numbers, and related operations |
| `3_Function` | Functions — declarations, expressions, scope, etc. |

> More topic folders may be added over time as new concepts are covered.

## 🚀 Getting Started

To explore or run the code locally:

```bash
git clone https://github.com/aditya2025-code/--JavaScript--.git
cd --JavaScript--
```

Each folder contains standalone `.js` files. You can run them with Node.js:

```bash
node path/to/file.js
```

Or open them directly in the browser console for quick experimentation.
